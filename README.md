# Комментарии к статьям (`mattweb.comments`)

Модуль для 1С-Битрикс, предназначенный для добавления системы комментариев к элементам инфоблоков.

Модуль можно использовать для организации комментариев к новостям, статьям и другим элементам инфоблоков без необходимости изменять структуру самого инфоблока.

## Возможности

- Комментарии к элементам инфоблоков;
- Ответы на комментарии;
- Древовидная структура комментариев;
- Модерация публикации комментариев;
- Удаление комментариев;
- Два режима удаления комментариев:
  - Каскадное удаление;
  - Установка отметки удаления;
- Лайки и дизлайки;
- Жалобы на комментарии;
- Подписка на ответы;
- Email-уведомления;
- Поддержка авторизованных и неавторизованных пользователей;
- Ограничение количества комментариев от пользователя;
- CAPTCHA;
- Поддержка нескольких типов смайлов;
- Административное управление комментариями, голосами, жалобами и смайлами.

---

## Архитектура

Модуль разработан с использованием **D7 ORM совместно с legacy API Битрикс**.

D7 ORM используется для работы с основными сущностями модуля:

- `CommentTable`;
- `VoteTable`;
- `SmileTable`;
- `SmileTypeTable`.

Legacy API Битрикс используется в тех местах, где это необходимо для взаимодействия с существующими механизмами платформы, например:

- `CIBlockElement`;
- `CIBlockSection`;
- `CEventType`;
- `CEventMessage`.

Таким образом, модуль сочетает современный ORM-подход с API, используемым ядром 1С-Битрикс.

# Основные ORM-сущности

## CommentTable

Основная ORM-сущность комментариев:

```php
\Mattweb\Comments\CommentTable
```

Таблица:

```text
el_comment
```

Основные поля:

| Поле | Назначение |
|---|---|
| `ID` | ID комментария |
| `IBLOCK_ID` | ID инфоблока |
| `SECT_ID` | ID раздела |
| `ELEM_ID` | ID элемента инфоблока |
| `PARENT_ID` | ID родительского комментария |
| `DEPTH_LEVEL` | Уровень вложенности |
| `CREATED_AT` | Дата создания |
| `PUBLISHED` | Опубликован ли комментарий |
| `DEL_MARKED` | Отмечен ли комментарий как удалённый |
| `USER_ID` | ID пользователя |
| `USERNAME` | Идентификатор пользователя |
| `NAME` | Имя автора |
| `HOMEPAGE` | Сайт автора |
| `IP` | IP-адрес |
| `EMAIL` | Email автора |
| `COMMENT` | Текст комментария |
| `SUBSCRIBE` | Подписка |
| `JC_ID` | Старый ID комментария |

Для голосов используется ORM-связь `OneToMany`:

```php
(new OneToMany('VOTES', VoteTable::class, 'COMMENT'))
```

### Пример получения комментариев

```php
use Mattweb\Comments\CommentTable;

$result = CommentTable::getList([
    'select' => [
        'ID',
        'NAME',
        'COMMENT',
        'CREATED_AT',
        'PARENT_ID',
        'DEPTH_LEVEL',
    ],
    'filter' => [
        'ELEM_ID' => $elementId,
        'PUBLISHED' => 1,
        'DEL_MARKED' => 0,
    ],
    'order' => [
        'CREATED_AT' => 'DESC',
    ],
]);

$comments = $result->fetchAll();
```

## VoteTable

ORM-сущность голосования:

```php
\Mattweb\Comments\VoteTable
```

Таблица:

```text
el_comment_vote
```

Голос хранит:

- комментарий;
- пользователя;
- элемент инфоблока;
- IP;
- дату;
- значение голоса.

Используются два значения:

```text
1  — Like
-1 — Dislike
```

Для пары `COMMENT_ID + USER_ID` в БД предусмотрен уникальный индекс, предотвращающий повторное голосование пользователя за один комментарий.

# ORM-события

`CommentTable` использует ORM-события для выполнения дополнительной логики.

### После добавления комментария

```php
CommentTable::OnAfterAdd()
```

После добавления комментария может быть отправлено email-уведомление модератору.

### Перед изменением комментария

```php
CommentTable::OnBeforeUpdate()
```

Событие используется для получения предыдущих значений полей перед выполнением `UPDATE`.

### После изменения комментария

```php
CommentTable::OnAfterUpdate()
```

В частности, событие используется для обработки публикации ответа на комментарий и отправки уведомления автору исходного комментария.

# Компоненты

После установки модуля доступны два компонента.

## `mattweb:artcomm.list`

Основной компонент для вывода комментариев к элементу инфоблока и отображения формы добавления комментария.

Поддерживает:

- Список комментариев;
- Древовидное отображение;
- Ответы;
- Лайки и дизлайки;
- Смайлы;
- CAPTCHA;
- Подписку;
- Форму добавления комментария;
- Выбор обязательных полей;
- Ограничение длины имени;
- Минимальную и максимальную длину комментария;
- AJAX-взаимодействие.

### Основные параметры

```text
ART_ELEMENT_ID - идентификатор элемента инфоблока (статьи, новости или другие элементы инфоблока)
ART_IBLOCK_ID - идентификатор инфоблока
ART_SECTION_ID - идентификатор раздела инфоблока
ART_DETAIL_URL - URL детальной страницы (статьи, новости или другие элементы инфоблока)
COMMENTS_SORT -  сортировка комментариев
COMMENTS_STYLE - стиль отображения комментариев (древовидный или плоский список)
SHOW_COMMENTS_FORM - показать форму для добавления комментария
```

Сортировка:

```text
COMM_ASC - по возрастанию
COMM_DESC - по убыванию
```

Вид отображения:

```text
COMM_TREE - древовидный
COMM_LIST - плоский список
```

### Пример подключения

```php
<?php
$APPLICATION->IncludeComponent(
    'mattweb:artcomm.list',
    '',
    [
        'ART_ELEMENT_ID' => $arResult['ID'],
        'ART_IBLOCK_ID' => $arResult['IBLOCK_ID'],
        'ART_SECTION_ID' => $arResult['IBLOCK_SECTION_ID'],
        'ART_DETAIL_URL' => $arResult['DETAIL_PAGE_URL'],
        'COMMENTS_SORT' => 'COMM_DESC',
        'COMMENTS_STYLE' => 'COMM_TREE',
        'SHOW_COMMENTS_FORM' => 'Y',
    ]
);
?>
```

## `mattweb:artcomm.last`

Компонент предназначен для вывода последних комментариев.

Основные параметры:

```text
ART_IBLOCK_ID - идентификатор элемента инфоблока (статьи, новости или другие элементы инфоблока)
ART_PAGE_URL - URL детальной страницы (статьи, новости или другие элементы инфоблока)
ART_URL_PARAMS - Параметры URL для вывода статьи
COMM_SHOW_QUANT - количество комментариев для показа
COMM_MAX_LENGTH - максимальная длина комментария
COMM_DATE_FORMAT - формат показа даты
```

Формат показа даты:

```text
F1 - 01 Января 1970
F2 - 01.01.1970
F3 - 01.01.1970 01:00
```

Позволяет настроить:

- количество выводимых комментариев;
- максимальную длину текста;
- формат даты;
- URL страницы элемента.

### Пример подключения

```php
<?php
$APPLICATION->IncludeComponent(
    'mattweb:artcomm.last',
    '',
    [
        'ART_IBLOCK_ID' => 1,
        'ART_PAGE_URL' => '/news/',
        'COMM_SHOW_QUANT' => 5,
        'COMM_MAX_LENGTH' => 75,
        'COMM_DATE_FORMAT' => 'F2',
    ]
);
?>
```

# Пользователи

Модуль поддерживает работу с авторизованными и неавторизованными пользователями.

Для комментария могут сохраняться:

- ID пользователя;
- идентификатор пользователя;
- имя;
- email;
- сайт;
- IP-адрес.

Для авторизованных пользователей используется `USER_ID` Битрикс.

Для неавторизованных пользователей предусмотрен собственный идентификатор, используемый модулем при ограничении количества комментариев.

---

# Модерация

Для каждого комментария предусмотрены признаки:

```text
PUBLISHED
DEL_MARKED
```

`PUBLISHED` определяет, опубликован ли комментарий.

`DEL_MARKED` позволяет пометить комментарий как удалённый без физического удаления записи.

В настройках можно выбрать режим удаления:

```text
dm_cascade
```

или

```text
dm_mark
```

# Email-уведомления

При установке модуля регистрируются следующие типы почтовых событий:

```text
NEW_COMMENT_ADDED
COMMENT_REPLY_ADDED
NEW_COMPLAINT_ADDED
```

Они используются для:

- уведомления модератора о новом комментарии;
- уведомления автора комментария о новом ответе;
- уведомления модератора о новой жалобе.

Модуль создаёт необходимые почтовые события и шаблоны при установке.

# Жалобы

Пользователь может отправить жалобу на комментарий.

Для жалоб используется отдельный тип почтового события:

# Установка

Модуль устанавливается стандартными средствами 1С-Битрикс.

Скопируйте каталог модуля:

```text
/bitrix/modules/mattweb.comments/
```

После этого в административной панели откройте:

```text
Настройки → Модули
```

Найдите модуль **mattweb.comments** и выполните установку.

При установке:

1. создаются таблицы модуля;
2. регистрируются почтовые события;
3. создаются почтовые шаблоны;
4. устанавливаются компоненты;
5. устанавливается административная часть;
6. устанавливаются демонстрационные данные и файлы, предусмотренные установщиком.

SQL-структура находится в:

```text
install/db/install.sql
```

Удаление структуры БД:

```text
install/db/uninstall.sql
```

# Composer

Модуль не требует установки сторонних PHP-зависимостей через Composer.

Поэтому `composer.json` для текущей версии модуля не является обязательным.

Модуль использует API самого 1С-Битрикс и собственные классы.

Если в дальнейшем в модуль будут добавлены внешние PHP-библиотеки, их зависимости можно будет описать через `composer.json`.

# Требования

Модуль предназначен для установки в 1С-Битрикс.

Точная минимальная версия PHP определяется версией ядра 1С-Битрикс, в которой устанавливается модуль.

В текущей версии проекта отдельная минимальная версия PHP в коде модуля не зафиксирована.

Для публикации конкретного релиза рекомендуется указывать версию PHP и версию 1С-Битрикс, на которых данный релиз был протестирован.
